# 🌸 Sobre o Projeto

Este projeto é meu portfólio pessoal desenvolvido com foco em identidade visual, criatividade e experiência do usuário.

O objetivo foi criar um site que representasse minha conexão entre:
- 🎨 Marketing Digital
- 💻 Front-End
- 📱 Social Media
- 📊 Tecnologia & Dados

Todo o layout foi desenvolvido utilizando HTML, CSS e JavaScript puro, explorando uma estética inspirada em scrapbook, polaroids e interfaces criativas.

---

# 🚀 Funcionalidades

✨ Layout responsivo  
✨ Galeria horizontal interativa  
✨ Efeitos hover e animações  
✨ Vídeos incorporados  
✨ Design autoral  
✨ Navegação fluida

# 🎨 Conceito Visual

O design foi inspirado em:
- Scrapbook digital
- Polaroids
- Moodboards criativos
- Interfaces modernas de portfólio

A ideia foi fugir de um portfólio tradicional e criar uma experiência mais visual, dinâmica e com personalidade.
